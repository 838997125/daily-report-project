## 15. 文档维护说明

- **本文档（设计文档）何时更新**：架构/模块变化、新增外部依赖、部署形态变化、技术选型变更、路线图进展、新增未决风险时。相对稳定，不记日常流水。
- **《问题与决策档案》何时更新**：每次报错、异常、事故、处理决策时，追加一条（场景/根因/决策/经验）。
- **日报何时写**：每天每个工作会话一条最终情况摘要；项目类事项附本文档 + 档案链接。
- **每日异常流转**：日报条目（摘要）→ 问题与决策档案（详细复盘）→ 若涉及架构/新风险，更新本文档对应章节 + 风险登记册。
